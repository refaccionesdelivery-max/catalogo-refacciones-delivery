Para subir a GitHub:
1. Entra al repositorio.
2. Add file > Upload files.
3. Arrastra todos los archivos y la carpeta imagenes.
4. Commit changes.
5. Espera 1-3 minutos y actualiza con Ctrl+F5.

Para agregar más imágenes:
1. Sube la imagen a la carpeta /imagenes.
2. Edita index.html en la sección featured.
3. Usa nombres sencillos: inyector-hilux.jpg, marcha-l200.jpg, bomba-cat.jpg.
