CATÁLOGO WEB REFACCIONES DELIVERY

Archivos:
- index.html: página principal del catálogo.
- productos.json: base de productos tomada de REGISTRO PRODUCTOS.xlsx.

Para probarlo:
1. Descomprime la carpeta.
2. Abre index.html en Google Chrome.

Para publicar gratis en GitHub Pages:
1. Crea un repositorio nuevo llamado catalogo-refacciones-delivery.
2. Sube index.html y productos.json.
3. En Settings > Pages, selecciona Branch main y Folder /root.
4. Guarda y espera a que GitHub te genere el link.

IMPORTANTE:
- Cambia el teléfono de WhatsApp en index.html si deseas otro número.
- Puedes ocultar precios poniendo todos los precios en 0 o editando el HTML para mostrar solo “Cotizar”.
